# Eksperimen_SML_Cahyadi

Repository ini mengandung eksperimen preprocessing untuk Kriteria 1.

## Struktur

- `namadataset_raw/` : dataset raw untuk preprocessing
- `preprocessing/Eksperimen_Cahyadi.ipynb` : notebook preprocessing
- `preprocessing/automate_Cahyadi.py` : script preprocessing otomatis
- `preprocessing/namadataset_preprocessing/` : dataset yang sudah diproses
